# Атмосфера — дневник, который помнит, как ощущался день

Genesis Hackathon · ArtTech · «Make the Invisible Visible»

Текст о дне + фото + песня → анимированная страница дневника, которая передаёт атмосферу, папка дня с придуманным названием и архив. Правила визуальной системы описаны в [DESIGN.md](DESIGN.md), в приложении они на странице «Система». Материалы для сдачи (описание, приёмы, инструменты, сценарий видео) — в [SUBMISSION.md](SUBMISSION.md).

**Примеры дней** лежат в `public/examples` и сами открываются у нового посетителя с пустым архивом (в `docs/index.html` они вшиты внутрь). Обновить их: в `npm run dev` записать дни → внизу архива «Сохранить архив как примеры» → `npm run build:standalone`.

## Открыть без установки

Скачайте репозиторий и откройте **[docs/index.html](docs/index.html)** двойным щелчком: это весь сайт в одном файле (JS и CSS вшиты внутрь), сервер и `npm` не нужны. Дни сохраняются в браузере. Без сервера текст разбирает эвристика; всё остальное — шейдер, живой звук, календарь, показ, сравнение, видео — работает так же.

Ту же папку `docs` можно включить как GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `docs`.

Пересобрать файл после изменений: `npm run build:standalone`.

## Запуск

```bash
npm install
cp .env.example .env.local   # заполнить GEMINI_API_KEY (необязательно)
npm run dev                  # http://localhost:5173
```

Без ключей всё работает: текст разбирается эвристикой, дни хранятся в IndexedDB браузера.
С `GEMINI_API_KEY` подключаются анализ текста и фото, названия, оценка песни и второй слой ощущений «Глубже в день».
Исполнитель и название песни определяются сами — по ссылке (`api/song.ts`: Spotify, YouTube, SoundCloud, Яндекс Музыка, Apple Music) или по тегам аудиофайла.
С `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` архив становится общим (схема — [supabase/schema.sql](supabase/schema.sql)).

Модели Gemini выбираются цепочкой с таймаутами: `gemini-3.8-flash`, при перегрузке — `gemini-3.1-flash-lite`. Переопределить можно через `GEMINI_MODEL`.

**Возможности страницы дня:** «Прожить день» (шейдер и графика реагируют на живой звук песни), кинорежим (`#/day/<id>/kino`, стрелки листают дни, Esc — выход), ползунки осей «не так ощущалось» с живым предпросмотром, экспорт видео с музыкой, скачивание папки .zip, пересборка дня по текущим правилам, переименование папки.

**Календарь** (`#/calendar`, `#/calendar/2026-11`, `#/calendar/2026`): месяц с обложками дней по датам и «настроением месяца» (средние оси, градиент акцентов, фраза вроде «Ноябрь вышел тёплым и спокойным», песни месяца). Год — 12 месяцев, клетки в цвете дней. Пустая прошедшая дата открывает запись задним числом (`#/new?date=…`).

**Архив и показ:** «Год в цветах» (полоса года из палитр дней), «Год назад в этот день», сравнение двух дней (`#/compare/<id>/<id>`), показ для жюри (`#/show`: самые непохожие дни подряд с музыкой).

**Тестовые дни (dev):** в консоли браузера выполнить `await __seedDemo()`. Появятся 5 контрастных дней с синтетическими фото и треками, по одному на каждый режим.

## Деплой (Vercel)

Импортировать репозиторий: фреймворк Vite определится сам, файлы `api/*.ts` станут серверными функциями. В Environment Variables задать `GEMINI_API_KEY` и при необходимости ключи Supabase.

## Как устроено

```
api/analyze.ts        Gemini: текст + фото → оси настроения, название, подпись, оценка песни
api/feel.ts           Gemini: «Глубже в день» — 11 дополнительных осей ощущений
api/song.ts           исполнитель и название по ссылке на песню
src/lib/analysis/     фото (k-means палитра, свет, тепло), аудио (BPM, RMS, лад, фрагмент), текст (эвристика)
src/lib/rules/        движок правил: сигналы → оси → режим → параметры стиля + объяснения
src/components/memory/ страница дневника: убер-шейдер (R3F), графический слой (SVG), вёрстка
src/lib/storage.ts    папка дня: IndexedDB или Supabase; экспорт папки в .zip
```

## Использованные инструменты

React 19, TypeScript, Vite, Tailwind CSS 4, three.js + @react-three/fiber, motion, lucide-react, meyda, web-audio-beat-detector, wavesurfer.js, Web Audio API (живой анализ звука), MediaRecorder, @google/genai (Gemini 3.x Flash / Flash-Lite), Open-Meteo, Supabase, idb-keyval, JSZip. Шрифты Google Fonts: Caveat, Lora, PT Mono (интерфейс-скрапбук); Cormorant Garamond, JetBrains Mono, Unbounded (страница дня).

Собственная работа команды: движок правил и оси настроения, убер-шейдер (Кувахара, растр, дуотон, халация, рваный край, переходы), генеративный графический слой, аудиоанализ (метрическая проверка удвоения темпа, определение тональности по Крумханслу, выбор фрагмента), визуальная система.
